# 🚲 SOFTBYKE

**Site de apresentação e divulgação de uma empresa de bicicletas**

O Softbyke é um projeto acadêmico desenvolvido em grupo com o objetivo de criar um site para uma empresa do segmento de bicicletas, reunindo informações institucionais, produtos, galeria de imagens e canais de contato em uma interface web.

## 🎯 Objetivo do projeto

Desenvolver um site organizado e visualmente consistente, aplicando conhecimentos de desenvolvimento web front-end e trabalho colaborativo.

## ✨ Funcionalidades

- **Página inicial:** apresentação do site.
- **Produtos:** exibição dos produtos disponíveis.
- **Galeria:** apresentação visual de imagens.
- **Empresa:** informações institucionais.
- **Contato:** página com informações para contato.
- **Páginas informativas:** conteúdo complementar sobre a empresa e seus serviços.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 👩‍💻 Minha contribuição

O projeto foi desenvolvido em equipe, com divisão de tarefas entre os integrantes.

Minhas contribuições incluíram:
